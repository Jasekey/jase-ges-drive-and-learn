# JASE GES DRIVE & LEARN 🚗📚

A browser-based racing and learning game with a red-and-blue theme, made for GES JHS practice.

## Play the game
Open **index.html** in a browser, or enable GitHub Pages to publish it as a website.

## How to play
- Click **Start race** to race rival cars.
- Steer with **← / →** or **A / D**. On mobile, use the on-screen steering buttons.
- Collect coins and avoid cars and roadblocks.
- Answer GES subject questions at checkpoints to earn coins and learning points.
- Choose Mathematics, English, Science, Computing, Social Studies, French, or RME.
- Use coins to upgrade your car.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Choose **Pages** from the sidebar.
3. Under the build/deployment section, select **Deploy from a branch**.
4. Select the **main** branch and **/(root)** folder, then save.
5. Wait for GitHub Pages to publish the site. The website link will appear in the Pages section.

Progress is saved locally in the browser on the device you play on. This is an early playable version; questions are sample practice questions and should be checked against your class notes.
